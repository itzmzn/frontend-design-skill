## \[1.0.0\] - 2026-10-05

### Added

-   Initial public release of Frontend Design Skill.
-   Core `SKILL.md` with frontend design principles, workflow,
    implementation guidance, and reference routing.
-   Specialized design references for applications, commerce, editorial,
    education, games, marketing, mobile, portfolio, science, and spatial
    experiences.
-   Vendor-neutral guidance intended for use across capable AI coding
    agents.
-   Reference-driven structure for selecting design guidance according
    to the task.

### Changed

-   Reorganized the design guidance into a consistent `SKILL.md` and
    `references/` structure.
-   Renamed reference files with concise, descriptive filenames.
-   Rewritten and standardized the Markdown documentation for clarity,
    consistency, maintainability, and public use.
-   Generalized source-specific instructions into reusable frontend
    design guidance.

### Removed

-   Product- and platform-specific references not required by the
    frontend design skill.
-   Source-specific assumptions and terminology.
-   Redundant or obsolete wording from the original material.
